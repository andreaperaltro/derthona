DERTHONA BASKET BRAND ASSETS

This package contains the approved downloadable assets of the Derthona Basket
brand identity.

CONTENTS

01 Logos
Logo files are organized first by artwork version, then by intended background:

- Color / Light BG
- Color / Dark BG
- Monochrome / Light BG
- Monochrome / Dark BG

Each background folder is divided into SVG, PNG and JPG formats. Clear-space
constructions are stored separately in the Reference folder.

The Rose Symbol uses the same color artwork on light and dark backgrounds, so
the approved file is included in both Color folders for easier selection.

02 Fonts
Font packages for Derthona Display, PP Neue Montreal and PP Fragment.
The Derthona Display package includes desktop and web formats together with its
installation and usage guide.

03 Templates
Approved business card and letterhead templates.

04 Visual Language
Approved assets and examples based on The Curve visual system.

brand.md
Machine-readable operational brand guide.

SOURCE OF TRUTH

The online Derthona Basket Brand Manual is the primary and most current source
for brand rules, asset selection and usage guidance. Always consult the online
manual before using or distributing these files.
